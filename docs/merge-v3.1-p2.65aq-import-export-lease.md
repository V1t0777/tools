# 云屿 V3.1 · P2.65aq：导入进行中禁止导出过期快照（未发布）

## 风险与修复
普通经营模式已经将文件选择/读取/恢复作为互斥的写入意图，但三个导出按钮（普通存档、异常重置备份、恢复前备份）此前仅检查页面可见与运行时写锁。原生选择器尚未返回、文件读取未完成时，用户或迟到事件仍可能触发导出，下载到即将被恢复操作替换的旧快照；预检过程中还可能同步触发新选择器。

本轮在共享 `allowVisibleExport()` 增加 `importPending()` 拒绝与中文重试提示；在 `exportSourceStillCurrent()` 的读取前后均再次核验导入许可，覆盖下载授权前的重入竞争。所有三类导出统一受保护。取消导入后仍可主动导出，异常存档证据在没有导入意图时仍可只读保存。

## 回归
- 原生文件选择器等待期间，三种导出均被拒绝，不改存档或剧情键；显式取消后导出入口恢复。
- 文件读取挂起期间，三种导出均被拒绝；取消后迟到文件不得写入存档/恢复备份。
- 导出预检的存储读取同步打开文件选择器时，不得发起旧快照下载。

## 发行边界与剩余风险
这只是页面级导出许可协调，不使 localStorage 成为跨标签原子事务，也不证明浏览器下载实际落盘。真实 iPhone Safari/微信 WebView 的文件选择、取消、下载、BFCache 和双标签回归仍为发行阻塞。必须检查最终 HEAD 的全仓库 Node、security-check.sh/部署隔离、全历史密钥扫描三项 Actions；本轮不得自行发布、合并 main、触碰 Supabase 或正式部署白名单。保留 [CF-Pages-Skip]。
