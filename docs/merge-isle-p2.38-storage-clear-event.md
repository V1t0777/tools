# 《云屿百物铺》V3 · P2.38 跨标签 clear 事件存档移除保护（未发布）

## 问题
浏览器其他标签调用 `localStorage.clear()` 时，`storage` 事件的 `key` 为 `null`。现有普通模式监听器只接受 `SAVE_KEY`，因此不能立即发现整个存储被清空。虽然下次保存仍会因为 `expectedRaw` 不匹配而失败关闭，但用户可能在这之前继续看到旧进度并尝试操作。

## 本轮单一修复
- `merge/main.mjs`：监听器额外接受 `key===null`，并通过既有只读 `peekLocalV3` 检查当前真实存档。若已移除，立即暂停同步并提示备份核对；若存档原文未变，则不干扰游戏。其他无关键事件仍直接忽略。
- `tests/merge-storage-event-policy.test.mjs`：使用 Node vm 执行真实 storage 回调片段，验证清空导致存档消失时即时保护，以及存档未变化的 clear 事件不产生误报。禁止在事件回调写存档、迁移或重新生成存档。

## 验证与限制
此变更只改善跨标签存档清除的即时检测，不声称提供原子事务或解决同步 `localStorage` 的竞争窗口。Node vm 不是浏览器实机双标签验收，iPhone Safari、微信 WebView 仍需单独验证。仍未实现 Web Locks 页面全面接入、云存档或安全导入。
