# 《云屿百物铺》P2.13 — 普通模式长期经营里程碑（只读）

## 已落地的研发增量

新增 `merge/normal-milestone-rules.mjs`、`merge/normal-milestone-metrics.mjs`、`merge/normal-milestones.mjs`。仅从已通过 `validateSave` 的 V3 普通模式存档派生目标，不修改存档结构、经验门槛、体力、金币、委托、道具、建筑或商店规则。故事存档、混合模式对象和损坏存档被拒绝。

经营目标共九项：累计订单 **50/200/800** 次；累计合成 **150/600/2400** 次；完成既有三项建筑、仓库达到八格、现有三座工坊升至三级。它们只是长期展示建议，**不是新增等级、正式经济奖励或实测玩家留存结论**。

`deriveNormalMilestones` 输出当前值、截断进度、剩余量、百分比、完成状态和源存档修订号；输出对象被冻结，不持有输入存档的可变引用。固定 `rewardPolicy:'NONE'`：没有领取按钮、可领取凭据、发奖函数、库存刷新或重复奖励循环。当前 `merge/main.mjs` 未接入本模块，玩家界面保持原样。

## 双模式与长期剧情

普通模式仅使用已有 `progress`、`buildings`、`warehouse`、`board`。剧情模式保留 P2.12 的独立 `packs` 存档结构；主线、支线、突发事件和未来 DLC 不会为普通经营目标提供可伪造的货币或体力。首版不锁死终章与世界真相。未来跨模式奖励须另做服务端校验、去重和账户授权。

## 测试与后续

新增三组专项测试：初始存档、计数阈值及极大安全整数、建筑/仓库/工坊满目标、纯函数确定性、故事/混合/损坏输入隔离、冻结输出、静态无 I/O、未激活试玩界面。此处只证明代码契约；不能替代 Windows/iPhone 实机体验、真实玩家节奏研究或正式云存档验证。

后续可设计只读里程碑展示和更具策略性的经营任务；如需发放一次性奖励，先独立设计有限额、可验证、不可重复领取的权益账本并进行经济模拟。
