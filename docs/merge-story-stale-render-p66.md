# 《云屿百物铺》剧情 P66 · 旧按钮事件代际隔离（仅 Draft）

## 问题与范围

普通经营 P2.65a 已防止重新渲染后脱离 DOM 的订单、仓库、补给按钮重放；剧情专属工作台同样存在排队点击在棋盘选择、存档冲突或页面恢复后落到旧节点的风险。旧节点捕获订单 ID / 仓库槽位，但读取当前 state，可能把过时的玩家意图解释为对新状态的有效操作。

## 工程增量

1. **上游安全同步**：保留上游 P2.65a–b 原始提交与完整测试、文档；上游重叠变更路径在剧情分支均与合并基线 blob 一致，不覆盖剧情专属文件。
2. **剧情工作台代际保护**：每次完整 render 递增代际；7×8 棋盘格、仓库取回及委托交付按钮绑定创建时的代际。过期回调只显示“界面已更新，请在最新界面重新操作”，不选择、生产、交付、取回或自动重试。合法新按钮仍执行原引擎与原存档事务。
3. **专项测试**：验证旧委托、旧棋盘、旧仓库点击不执行；一次动作引发重绘后排队的第二次点击被拒；有效新按钮仍可执行；UI 入口接线、无动态 HTML、移动端提示区和触控布局契约保留。

## 不变量与限制

- 代际门禁只保护 UI 意图，不代替操作前精确原文校验、Web Locks、锁内 CAS、写后两次发布复核。其他标签若尚未触发重绘，仍由 P64 存档预检拒绝。
- 不改变存档 schema、普通/剧情资源隔离、经济数值、DLC 命名空间、正式导航、构建部署配置、生产数据库或 Cloudflare 设置。
- 仅运行 Node 单元与静态契约及 GitHub Actions；真实 Safari/微信 WebView 事件队列、BFCache、双标签并发及玩家经营节奏仍待设备验收。CI 不代表发行合格。
