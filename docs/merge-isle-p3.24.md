# 云屿百物铺 P3.24 本地数据库预验收可靠性（未发布）

本轮修复一次性本机 PostgreSQL 并发测试中异步子进程可能无限等待、输出不受限的问题。新辅助模块 `scripts/merge-pg-bounded-child.mjs` 通过无 shell 的进程启动方式执行独立测试命令，默认 15 秒超时及 4096 字节输出上限。超时、输出超限、启动失败或非零退出均返回固定失败，不展示原始输出。

`merge-receipt-pg-preflight.mjs` 的 40 个独立测试连接改用上述限额模块，数据库准入检查与 SQL 权限断言未改变。新增 Node 专项测试覆盖正常退出、非零退出、超量输出、超时、无效可执行文件、参数校验及接入约束。

自动化测试不能替代真实 PostgreSQL 并发、权限及 RLS 验证。验收以 GitHub Actions 全仓库测试、静态安全和完整历史扫描全部通过为准。PR #58 保持 Draft，不合并 main、不部署、不执行线上 SQL、不修改美术。
