# P110｜剧情主线、支线与故事卡片共用同次工作台读取（未发布）

## 修复与测试
剧情页一次渲染原先分别读取工作台来计算主线导航、支线导航和每张经营门槛卡片；若其他标签恰好更新订单或建筑，同一帧可能出现“已达标”与“未达标”矛盾提示。本轮在 `render()` 内只读取一次经过校验的剧情专属工作台存档，并将同一快照传给主线、支线和故事卡片；保留打开对白、点击导航、完成阅读时既有独立原始字节复核与 Web Lock/CAS，不扩大写入权限。

`tests/merge-story-render-snapshot-p110.test.mjs` 从真实 `ui.mjs` 挂载 DOM：第一项在单次读取返回旧字节后模拟另一标签替换，核对主线和第一单卡片一致、下次刷新一致且不写工作台；第二项模拟损坏工作台，确认不显示已解锁且保留原始存档和普通模式。仅是确定性故障注入，不是 iPhone/微信 WebView 真机或跨标签原子事务证明。
