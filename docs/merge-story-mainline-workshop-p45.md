# 《云屿百物铺》P45 · 经营成果在固定剧情章节中的确定性回应（仅研发分支）

## 叙事缺口
P30 让实际剧情工作台的委托与建筑状态影响每日随机事件；P42–P44 将五个经营目标与章节解锁、双向导航连接起来。但玩家如果没有抽中相关事件，在完成真实合成经营目标后，固定主线仍主要沿用静态对白，经营劳动缺少及时的叙事回应。

## 实际增量
新增 `merge/story/mainline-workshop-context.mjs`：五个既有经营目标的首卷章节在**实际剧情工作台持久化存档有效且对应目标已达标**时，追加一句人物反馈：
- `first-order`：交付真实街坊委托后，阿澄承认经营劳动。
- `toolbox`：实际收纳一件材料后，学徒理解仓库安全；仍是可选支线。
- `tea-table`：修复花园后，晚禾认可修复成果，但不强制种子萌发。
- `harbor-light`：修缮港湾后，岚叔仍强调雾天不得贸然出海。
- `festival`：修整门面后，阿澄准备庆典，同时保留后续篇章悬念。

严格复用 `storyWorkshopRequirement`，不复制经济阈值。只为首卷真实条目对象生效，要求剧情前置节点已经完成；同 ID 的 DLC 对象不会继承首卷文本。没有存档、异常存档或目标未完成时，不伪造反馈。原有对白和选择完整保留，仍由 `textContent` 渲染。

不新增金币、经验、体力、建筑、订单、物品、存档字段或网络依赖，不修改正式导航与构建白名单，不改章节前置条件。回看剧情时可根据**当前**真实经营状态显示/隐藏附加对白，不构成不可逆历史事件。
