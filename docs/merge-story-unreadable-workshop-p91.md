# 云屿剧情 P91 · 未读工作台快照与对白授权（未发布）

## 真实缺陷
旧剧情页在打开对白时若独立工作台损坏/不可读，`openWorkshopCurrent()` 会因 `selectedWorkshopReadable=false` 无条件放行。另一标签页随后修复、重置或替换工作台，即使旧页面漏收 `storage` 事件，仍可能沿用旧对白的选择和经营语境。非经营门槛剧情不应因此失去全部阅读能力，但也不能把不可读状态当成永久授权。

## 本轮修复与验证
- 剧情页记录对白打开时的工作台原始字节及不可读原因；在选择及确认前重新读取，只有**相同不可读原因 + 完全相同原始字节**才允许继续。变化后要求关闭重开对白；真实建筑门槛仍独立拒绝未达标状态。
- 正常可读工作台继续使用原有精确原始字节快检，不增加热路径额外校验；未改剧情章节、经济数值、存档 schema 或普通模式。
- `tests/merge-story-dialogue-unreadable-workshop-p91.test.mjs` 覆盖异常 UTF-16 原始记录不变、同标签缺失事件的对端修复、损坏内容替换、存储不可用及原有可读快照 CAS；检查实际 UI 两处授权入口接线。
- 同步上游 #58 P2.65z 原生选择器无 `cancel` 返回恢复机制，合并前需确认共同祖先、四个文件 Blob SHA 与剧情侧未重叠，保持双父历史与禁止强推。
