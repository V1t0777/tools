# P99｜剧情双页面 BFCache 存档复核重入阻断（2026-10-28）

## 缺陷与影响

剧情对白与独立工作台在 `pageshow` / `visibilitychange(visible)` 时会读取本地存档，核对是否与进入后台前的原始字节一致。此前如果 `localStorage.getItem()` 的同步执行期间再次触发 `pagehide` 或 `visibilitychange(hidden)`，即使读到的存档字节没有变化，旧的恢复流程仍可能清除“已暂停”标志，重新启用重置等操作。这不是存档内容冲突，而是页面生命周期许可失效。

## 本轮修复

- 剧情对白、剧情工作台各自维护独立的生命周期代次；只有 `pagehide` / hidden 暂停会推进代次，正常剧情每日事件固定、存档读取不会误触发。
- 开始只读恢复核对时捕获代次；所有同步读取和剧情依赖核对完成后再次核验代次、页面可见性及 BFCache 的 `pageshow` 许可。任何新的离开事件均保持暂停，等待下一次真实可见返回后重新核对。
- 不重放玩家动作，不修改经济、存档格式、剧情进度、普通模式键或安全门禁。工作台与对白的既有 Web Locks / 原始字节 CAS 继续有效。

## 专项 Node 回归

- 剧情页面 BFCache 返回时，在未变化的对白存档读取中同步触发第二次 `pagehide`：旧页面不得重置，下一次合法 `pageshow` 后才允许重新操作。
- 剧情页面可见恢复时，存档读取中同步触发 hidden：旧恢复不能解锁重置，新的 visible 事件必须重新核对。
- 工作台 BFCache 返回时，在未变化的工作台存档读取中同步触发第二次 `pagehide`：工作台不得重置，下一次合法 `pageshow` 后可恢复。

专项测试运行真实页面入口模块的 DOM 事件模拟；不是 iPhone Safari 或微信 WebView 实机测试。
