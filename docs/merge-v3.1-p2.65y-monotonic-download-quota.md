# 云屿 V3.1 P2.65y｜下载 Blob URL 单调时钟与重入额度保护（2026-10-28）

## 发行阻塞与范围

普通经营模式三类本地导出共用 `merge/save-download.mjs`。此前 Blob URL 的 120 秒清理期限默认使用 `Date.now()`，如果 iPhone/微信 WebView 在原生文件保存仍未结束时发生系统时钟向前校正，清理回调可能错误判断 URL 已过期并过早撤销，导致下载无法完成。另有极端同步重入：创建 Blob 尚未分配 URL 时，另一下载请求可在时钟跨越期限后回收尚未分配的额度，突破最多 8 个待清理链接的上限。

## 本轮修复

- 默认清理期限使用同一页面内的 `performance.now()` 单调时钟（向下取整），避免系统墙上时间跳变提前撤销下载 URL。旧浏览器没有该接口时保留 `Date.now()` 兼容路径；接口存在但异常时安全拒绝，不伪造成功。
- 清理过期链接时只回收已经取得真实 Blob URL 的条目；仍在同步创建过程中的额度始终保留，防止嵌套下载突破上限。
- 不改变 120 秒最小保留期限、8 个 URL 上限、原始存档字节、跨标签一致性复核或下载失败的安全反馈；下载成功仅表示原生点击已请求，不能证明文件实际落盘。

## 可复核测试与风险

- 新增四项 Node 专项回归：墙上时间前跳仍不提前撤销、旧浏览器无 `performance.now()` 回退、单调时钟异常安全拒绝、Blob 构造期间重入且时间跨越期限仍保持 8 个额度。
- 本地针对精确源文件执行 `node --test tests/merge-save-download-monotonic.test.mjs` 和 `node --check merge/save-download.mjs`；提交后仍须核对新 SHA 的全仓库 Node、`bash scripts/security-check.sh`/部署隔离、完整历史密钥扫描三项 CI。CI 不能替代 iPhone Safari、微信 WebView 双标签和文件下载落盘实测。
- 旧浏览器的墙上时钟回退路径仍受设备时间跳变影响，不能在缺少单调时钟时保证相同性质；浏览器完全冻结计时器时仅能在下次用户请求下载时补偿清理。
- 本轮仅修改普通模式下载模块、专项测试和此文档；不修改 story、main、导航、部署白名单、Supabase、云存档，不发布。
