# P31 · 已完成选择在日常事件中的回响（未发布）

## 问题与边界
第一卷现有主线与人物支线选择虽会持久化到独立剧情存档，但在后续日常事件里基本只用于回看，玩家不易感受到选择被记住。P30 已为六条事件加入真实工作台建设/委托回声；本轮增加**独立于经济存档**的三组剧情选择回声，不改变每日事件抽取或经济奖励。

## 实际改动
- 花园事件「忽然下起的雨」读取已完成的主线 `seed`：保留旧种子 / 尝试新花，分别呈现不同的晚禾后续对白。
- 港湾事件「海雾来得太快」读取已完成的主线 `apprentice`：示范 / 鼓励尝试，都坚持安全停工与复核，不因选择而虚构恢复航线。
- 来客事件「路过的旅人」读取可选人物支线 `postcard`：鼓励寄出 / 尊重暂缓。只反映决定，不声称明信片已经寄达。
- 新增纯只读 `incidentChoiceEcho`：严格验证剧情进度、核心事件对象、节点已完成及选择 ID；未完成、坏档、未知或同名 DLC 事件均不注入对白。页面仍通过 `textContent` 呈现，工作台坏档/未创建时也能独立显示已确认的剧情选择回声。
- 未改 `CORE_STORY_PACK`、存档 schema、既有选择、主线/支线门槛、订单、资源、建筑、日常哈希、部署入口及普通模式。
