# P77｜首卷四章有限补给新手压力回归（仅研发）

## 范围与变更

- 剧情分支 PR #59：在既有离线真实 7×8 引擎的审计模拟器中增加显式 `novice-supplies` 策略，沿用原新手偏离目标生产顺序，不修改任何玩家运行时经济规则。
- 体力耗尽时优先消耗已获得的一次性便当或汽水；如没有库存，仅在扣除汽水价格后仍保留**下一处完整建筑金币成本**、且限购未满时购买汽水。没有无限补给、自动刷新库存或作弊入口。

- 新增只读审计字段：补给购买/使用次数、补给花费、冷却卡次数与每次购买前的建设储备快照；不持久化、不上传、不影响玩家存档。新增 16 个固定种子的首卷主线完整门槛回归与确定性/有限库存/预算断言。
- 同步普通经营 PR #58 的 P2.65k–l，合并前核对共同祖先与五个变更路径，不修改剧情与普通模式共享经济规则。
