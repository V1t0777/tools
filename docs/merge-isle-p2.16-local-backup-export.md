# 《云屿百物铺》P2.16 — 普通模式原始本地存档导出

## 已实现范围

普通游玩模式预览界面在「重置试玩进度」旁新增「导出原始存档」。`merge/save-export.mjs` 只读取既有 `toolbox.merge-isle.local.v1` 存档键，按浏览器**实际已持久化的原始字符串**生成可下载文件，不导出可能尚未保存成功的内存进度。此举可在重置、浏览器迁移前尽量保留人工恢复所需数据。

- 若原始数据通过 V3 `validateSave`，导出 `yunyu-normal-save-v3.json`。
- 若数据异常、版本未知或超过正常存档校验上限，仍在 2,000,000 UTF-8 字节安全导出预算内按**原样**导出 `yunyu-unverified-original.txt`，不尝试自动修复、不标为有效存档。
- 若浏览器拒绝读取、没有存档或数据过大，明确提示失败，绝不覆盖原存档。
- 通过浏览器 `Blob` 和临时对象 URL 触发本地下载，不执行 `fetch`、云端上传、导入、数据库写入或 `localStorage.setItem`。
- 下载按钮移动端至少 44px 触控高度；与重置按钮在窄屏自动换行。纯文本与 `textContent` 渲染，不把不可信原始数据注入页面。
- **剧情模式保留独立名称空间**；本轮不读取、写入或导出剧情存档，也不影响金币、体力、背包、订单或奖励。

## 安全限制与实际验收边界

- **下载请求不等于下载成功**：iOS Safari、微信 WebView、隐私浏览器或企业管理浏览器可能拦截或改为打开 Blob。需要用户确认文件真实存在、内容完整，且在安全位置保存后才考虑重置或清理浏览器数据。
- **导出不等于可恢复**：本轮没有导入/还原按钮，也没有云同步。异常存档的文本文件只作人工取证与恢复原始字节的线索，不能当成经过校验的有效 V3 存档导入。
- 文件可能包含游戏进度等个人使用数据，应由玩家自行安全保存，不向陌生人共享。原始异常数据可能包含不可解释内容，始终按不可信输入处理。
- **P2.33 加固：**导出上限 `MAX_EXPORT_BYTES=2_000_000` 现在按实际 `TextEncoder` UTF-8 字节数限制（同时先执行 UTF-16 字符单位长度预筛查），避免中文/表情内容绕过文件体积预算。编码器不可用时禁止启动不可靠的下载并提示保留原存档。注意浏览器 `Blob` 的 Unicode 编码会将孤立代理项规范化为替换字符，因此“原样”指正常可编码文本的原始字符内容，不能保证损坏 UTF-16 代理项的逐单元还原。
- 同一时刻的其他标签页可能更新存档；导出仅对应 `getItem` 调用时读取到的快照，不保证跨标签事务一致性。
- 真正可发布的离线体验版仍需要**安全导入/恢复、冲突处理、真机下载验证与回滚演练**；本次不声称这些工作已经完成。
