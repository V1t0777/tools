# 《云屿百物铺》P75｜剧情补给与首卷建设金币储备

范围：仅 Draft PR #59 的离线剧情工作台，非发布。

## 用户风险
P74 让剧情玩家可购买有限补给。购买会消耗首卷建设所需金币；原页面只有通用提醒，未告知下一处建设的精确缺口，玩家可能误以为被卡关。

## 处理
- 只读计算尚未完成的第一处规划建设（花园→港湾→门面）所需金币与当前差额。等级和剧情门槛仍需另外满足；不修改建筑价格、补给价格、金币产出或故事解锁。
- 只有购买后会**从已足够建设变成不足**时，提示“将动用建设储备”并要求一次明确确认；取消不写存档。用户仍可自主购买，绝不引入作弊、自动补贴或无限循环。
- 确认后仍使用原有渲染代际防重放、原始字节预检、Web Lock/CAS、写后复核；保留独立剧情存档与普通经营模式隔离。预算文字与商店通过 aria-describedby 关联。

## 自动化与边界
新增纯函数测试覆盖花园/港湾/门面、差额、已完成及无效状态；真实剧情工作台 DOM 测试覆盖拒绝和同意动用建设储备、库存、金币与双模式隔离。同步 PR #58 的 P2.65i–j 普通存档导入/旧文件选择器防重放，双父非强推合并，六处文件事前核对没有故事分支重叠修改。

自动化测试不代表 iPhone Safari、微信 WebView 的原生确认框、文件选择器、下载落盘和真实跨标签并发已通过。仍需手工设备验收。不得写 main、发布、触碰线上 Supabase 或改变 Draft 状态。
