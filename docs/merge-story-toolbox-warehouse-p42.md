# 《云屿百物铺》P42 · 岚叔支线的真实仓库委托与选择反馈（未发布）

## 叙事与玩法增量
《工具有自己的位置》（岚叔人物支线）从单纯阅读升级为**可实际完成的仓库整理委托**：玩家需要在独立的剧情合成工作台中，将至少一件材料真实收纳进仓库，才能确认支线完成。玩家可选择「给收纳的材料做标签」或「先整理出安全通道」；如在《大家的开张庆典》前完成，学徒/岚叔会对不同选择给出各自的后续回应。未完成这条可选支线也能继续主线；不改变世界真相或 DLC 扩展空间。

- `merge/story/core-pack.mjs`：重写该支线四句对话，增加两个有区别且重视安全的选择。原先已经完成该支线的老存档仍可读；没有新选择的老存档不伪造回声。
- `merge/story/workshop-gate.mjs`：新 `warehouse` 目标类型读取**通过引擎校验的真实仓库**，仅统计容量内的非空物品。缺失、损坏、无效存档不能伪造达成；材料取回后未提交的支线将再次锁定。
- `merge/story/dialogue-commit-guard.mjs` 原有锁内快照核验自动覆盖此目标：用户点击确认后、等待对白锁期间若仓库被其他标签取空，拒绝提交而不覆盖剧情进度。
- `merge/story/mainline-choice-context.mjs`：在《大家的开张庆典》添加首卷可选支线回声，依旧要求完成记录+有效选择+精确首卷条目对象引用；DLC 同名节点不能继承。未完成支线不改变庆典主线。
- `merge/story/ui.mjs`、`merge/story/story.css`：所有经营门槛的故事卡与对话提示显示真实当前/目标进度；工作台损坏时明确提示核对，而非虚报 `0/1`。窄屏状态标签允许换行，文本通过 `textContent` 呈现，保留触控尺寸、安全区、深色模式与减少动态效果设置。

## 验证与边界
`tests/merge-story-toolbox-warehouse-p42.test.mjs` 覆盖引擎真实收纳/取回、存档损坏与模式隔离、锁等待期间撤回仓库物品、锁内成功提交、双分支庆典反馈、DLC 身份隔离、旧版无选择已完成存档及移动 UI 合同。须在最终提交 SHA 的 CI 中通过全仓库 Node 测试、`bash scripts/security-check.sh` 与完整 Git 历史密钥扫描，才能标记本轮工程验证通过。

当前只验证单浏览器存储模型和模拟锁，不能替代 iPhone Safari、微信 WebView、真实双标签、离线恢复、真人阅读节奏验收。支线完成后若再取出材料，已经提交的叙事记录不会撤销；此为一次性委托语义，不是永久库存锁定。
