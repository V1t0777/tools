# 《云屿百物铺》V3 · P2.25 跨标签存档事件只读同步（未发布）

## 本轮变更

针对现有普通模式 UI 的 `storage` 事件，修复其使用 `loadLocal` 和立即调用 `persist()` 的副作用。旧逻辑在响应另一标签页的写入时可能执行旧版存档迁移/备份，并再次写回普通模式存档；这不是理想的只读同步流程。

- 在 `merge/storage.mjs` 新增 `peekLocalV3(storage)`，只读取并校验 V3 原始存档；遇到缺失、异常、过大或旧版存档时拒绝采用，不触发迁移、不写备份、不把缺失视作空白新存档。
- 在 `merge/main.mjs` 的 `storage` 事件处理中使用只读检查；已知较新或同版本但原文不同的合法远端存档可以更新内存及原始基线，但**不会立即回写**。本地存在保存异常或远端修订号更旧时不覆盖当前内存进度，提示冲突并暂停自动同步。
- 异常/移除存档只更新 UI 提示，不尝试保存或重置，避免用户误以为数据已恢复。
- 专项回归 `tests/merge-storage-event-readonly.test.mjs` 验证原始字节、损坏/旧版/缺失/不可读存档只读、剧情键隔离和 UI 事件处理无写入调用。

## 剩余风险

这是对现有同步页面的**小范围安全修复**，并不表示 P2.22—P2.24 的异步 Web Locks/Checkpoint 已接入正式游戏。现有普通模式游戏动作、定时体力恢复和启动时旧存档迁移仍调用同步 `saveLocal`，无法获得完整跨标签事务保证。存档事件在本地保存异常时只保留当前内存状态，玩家应先备份并刷新核对，不能静默覆盖另一标签页。

本轮未执行浏览器双标签真机、iPhone Safari、微信 WebView 或断电故障测试；Node 静态 UI 断言不等于浏览器交互验收。后续需要真实浏览器跨标签测试，再决定如何渐进接入统一异步写入机制。
