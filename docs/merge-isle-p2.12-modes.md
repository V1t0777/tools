# 《云屿百物铺》P2.12 — 双模式存档与可扩展剧情包边界（未开放玩法）

## 决策背景与不可破坏的前提

《云屿百物铺》计划长期同时提供 **普通游玩模式** 与 **剧情模式**。普通模式强调合成、委托、仓库与自由经营；剧情模式承载精心设计的长期主线、支线任务、突发事件和未来 DLC。首版剧情**不锁死整体世界真相，不把最终结局硬编码进存档协议**；新内容包应可逐步追加，并保留角色关系与选择的延续性。

本阶段 **仅建立纯函数与数据契约**，不是在 P2 试玩界面发布模式选择按钮、剧情、角色、美术或 DLC。不可把“架构预留”误当成游戏已经支持剧情玩法。

## 已落地的只读/内存数据边界

新增 `merge/mode-boundaries.mjs`：

- `GAME_MODES.NORMAL = 'normal'`：沿用**原封不动**的正式研发预览本地存档主键 `toolbox.merge-isle.local.v1`。现有 `schemaVersion=3`、金币、经验、体力 120、四种补给、委托、仓库与成就全部不迁移、不清空、不重算。
- `GAME_MODES.STORY = 'story'`：**预留**独立的 `toolbox.merge-isle.story.local.v1` 名称空间。注意当前预览不会读取或写入这个键，也不会自动生成剧情存档。
- `createEmptyStoryProgress()` 生成 `{schemaVersion:1,mode:'story',revision:0,activePackId:null,packs:{}}`。不假定起始章节、固定终章、世界终极真相或 DLC 数量。
- `createEmptyStoryPack()` 提供每个内容包独立的 `checkpoint`、`completed.main`、`completed.side`、`completed.incident`、`choices` 和布尔 `flags`。支线、突发事件与人物选择可以与主线分开演进；DLC 示例命名 `dlc.mist-harbor`，并不意味着已经写出相应剧情。
- `registerStoryPack(save, packId)` 是**纯内存**、幂等且有预算限制的内容包登记函数。它不读取浏览器存储、不调用网络、不写数据库、不产出任何玩家道具或货币。
- `validateStoryProgress` 对顶层字段精确校验，拒绝非剧情模式对象、意外出现的 `coins`/`energy` 等字段、重复进度、错误章节 ID、恶意保留字段和畸形选择/事件；最多 24 个包、每类记录 512 个节点、每包最多 256 个选择与布尔标志，序列化尺寸不超过 128,000 字符。版本和数量界限以后变更必须单独设计兼容迁移。

**默认不可跨模式传递经济权益**。普通模式物品、金币、体力和排行榜不可由剧情包进度直接写入；剧情奖励若未来允许共享，必须另行设计服务端可验证的凭据和明确的账户授权机制。静态网页里的隐藏码不是身份验证，预留架构不会加入后门。

## 自动化回归

`tests/merge-mode-boundaries.test.mjs` 验证：

1. 普通存档键及 V3 引擎完全保持原样，剧情键严格不同；
2. 空故事进度有效，但无法作为普通模式存档写入；
3. 主线、支线、突发事件、决策记录分包保存且无相互污染；
4. DLC 包登记保持幂等，不修改输入对象；
5. 不接受包含普通模式货币、体力、伪造字段或不存在的 `activePackId` 的剧情对象；
6. 拒绝恶意/错误 ID、原型相关保留名称、重复章节记录；
7. 固定内容包与体积上限，阻止超大/损坏进度进入未来存档路径；
8. 当前 `merge/main.mjs` 未接入故事模式，现有 `saveLocal` 不会写故事名称空间，故不会突然修改用户游戏进度。

这些是**代码契约测试**，不等于未来用户可以在游戏界面选择模式，也不等于云端故事存档已经就绪。上线前还需要用户界面交互、剧情数据版本迁移、脚本事件权限和跨设备冲突解决的独立设计与实测。

## 后续分阶段设计建议（非本轮实装）

- P2.13 起：优先建立**普通模式独立的长期经营目标**（不降级现有玩家），用只读进度展示验证节奏；避免增加机械等待。
- 剧情 Alpha：先设计内容包接口与事件调度，主线/支线/突发事件分流、奖励边界及选择回溯策略；故事脚本只读取受限数据，不拥有直接改写普通存档的能力。
- 后续版本：模式选择屏、剧情档案管理、情节补丁升级、可选择式事件分支以及 DLC 包的版本控制、向前迁移、跳过旧内容的补偿策略。重大故事真相与封闭结局必须留在叙事策划阶段，不写死协议。
- 实机：正常与剧情模式分别设计 Windows、iPhone Safari、微信 WebView 和跨设备端到端测试；没有实际接线前不得称其验收通过。
