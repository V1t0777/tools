# 《云屿百物铺》V3.1 · P2.65g 多点触控与过期触点防护

**范围：** Draft PR #58 普通经营模式独立研发分支。只修复离线 Web 首发的触控 P0 风险，不修改剧情文件、正式入口或部署配置。

## 问题与修复

移动浏览器可能在材料拖动时接收到第二个手指的 pointerdown。此前该事件会覆盖当前 drag.id 与 origin，导致双指滚动/缩放时的悬浮拖拽和落点归属不确定；非主指针也可能直接发起拖动。另一个边界是完整重绘后旧 DOM 的迟到 pointerdown，以及不在格子上的触点错误清除取消手势的兼容点击屏蔽。

本轮将普通模式拖动限制为单个主指针：已有拖动时任何第二次 pointerdown 都同步取消旧手势；明确的非主指针不启动拖动。只有属于当前棋盘的格子才能启动新手势并清除旧兼容点击屏蔽，脱离棋盘的节点和棋盘空白处均不能解除该保护。没有新增依赖、存档写入或网络请求。

## 回归与验收

实际 merge/index.html 入口的 DOM 回归新增四个场景：双指打断后双方 pointerup 和迟到 click 均不写入；非主指针不能启动拖动、主指针可正常合成；重绘后的旧格子不能再次发起拖动；背景触点不能解除已取消拖动的 click 屏蔽。保留原有 Web Locks、跨标签与 BFCache 测试。

代码变更后以该**新 SHA**对应的 GitHub Actions 核验全仓库 Node、静态安全/部署隔离（含 scripts/security-check.sh）、完整历史密钥扫描。GitHub CI 不代表 iPhone Safari/微信 WebView 实机测试；仍须真机验证双指滚动、缩放、拖拽、后台恢复及文件下载落盘。Cloudflare 预览部署关闭设置仍未获独立接口验证；不得将无 GitHub 部署检查等同于零部署。
