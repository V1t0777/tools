# 《云屿百物铺》V3.1 · P2.65j 文件选择器旧授权隔离

范围：仅 PR #58 普通模式独立研发分支，未修改剧情源文件、共享 HTML/CSS、main 或部署白名单。

## P0 风险与修复

P2.65i 在文件读取和恢复确认阶段会核验 Web Locks、原始存档和页面生命周期，但实际页面从点击“导入”到系统文件选择器返回之间没有绑定原始存档和页面 epoch。若在选择器打开期间发生 BFCache/pagehide、隐藏态切换或跨标签采用新存档，旧选择器的 change 事件可能基于**新的**原始存档重新发起确认。这不符合“旧手势不得自动作用于新棋盘/新存档”的交互原则。

现在仅在用户主动点击导入、当前页面与存档完成只读核验后，记录当时的精确 raw 与 importEpoch。文件选择器返回时必须匹配这两个值，且再次只读核验；否则清空选择器并要求用户重新点击导入。pagehide、隐藏态、选择器 cancel 会撤销旧授权。原有文件大小、模式隔离、降级双确认、Web Locks、恢复前原始备份与读回验证保持不变。

## 自动化回归与剩余风险

扩充真实普通页面入口 DOM 回归：正常导入/用户取消保留，新增 BFCache 旧选择器、跨标签进度变化、未经用户点击的 change、取消后迟到 change 的无写入验证。须以本提交对应的 Node 全仓回归、安全检查和完整 Git 历史密钥扫描为准，CI 不等于 iPhone Safari 或微信 WebView 实机验收。

移动端系统文件选择器可能触发隐藏态，因此安全策略可能要求重新选择文件；这是宁可拒绝旧授权也不覆盖不明存档的保守设计。后续真机需核对文件选择、取消、BFCache 往返与真实文件下载落盘。禁止自动部署、合并或发布。
