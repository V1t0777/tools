# 《云屿百物铺》V3.1 · P2.64d 候选页移动端取消手势与恢复路径回归

**状态：仅 Draft 研发分支的持锁候选页面，尚未切换 `merge/index.html`；不代表真实浏览器或 RC 验收。**

## 本轮同主题增量

1. **修复移动端 `pointercancel` 后迟到兼容点击。** 旧 `completeDrag` 在 `cancelled` 为真时直接返回，没有启用 `ignoreNextClick`。部分浏览器/触控辅助设备若在取消后仍派发兼容 `click`，可能触发新的生产或选择操作。现在只要取消了已经捕获的手势，就阻断其迟到的指针点击；新的真实 `pointerdown` 会清除此保护，键盘 `detail===0` 不受影响。
2. **异步保存期间清理悬浮拖拽。** `pointermove` 发现存档已阻断或 Web Locks 事务在途时，立即取消旧手势并移除拖拽幽灵元素，避免在锁等待时仍展示可以投放的假象。真实的存档写入仍全部交由统一事务处理。
3. **扩大候选页 DOM 组合回归。** `tests/merge-locked-page-dom.test.mjs` 新增五项：取消手势后的迟到点击与新手势恢复、BFCache 前后台恢复后采纳合法外部进度、页面隐藏时在途动作不发布过期 UI、保存忙时拖拽幽灵元素清理、损坏原始存档仍可只读请求导出。使用 Node 模拟 DOM/Storage/Web Locks 驱动真实 `main-locked.mjs`，不是 iPhone Safari/微信实机测试。

## 兼容性和安全不变量

- 不修改普通模式经济参数、存档格式、锁名称、剧情模式命名空间或正式入口。
- 已阻断的存档会话不能借页面恢复、点击或拖拽自动重新开放写入；已提交但失效的在途事务不能冒充回滚成功。
- 取消手势只阻断迟到的非键盘兼容点击；下一次实际 `pointerdown` 可以正常操作。
- 损坏存档的导出仍然只读，不要求先重置或解析成功，也不会触及剧情存档。
