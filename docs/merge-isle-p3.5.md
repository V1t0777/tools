# 云屿百物铺 P3.5 — 本地存档失效保护与回归测试（仅开发分支）

**发布边界：** 本轮只修改 P2 本地试玩存档读取/写入保护、异常提示、单元测试；不接入云存档，不改数据库、Edge Function、正式导航、部署白名单或美术。

## 风险与修复

原来的 `loadLocal()` 在遇到损坏的 v2 JSON、非法 schema 或浏览器拒绝读取时会返回初始游戏；`main.mjs` 启动时紧接着调用 `persist()`，可能把原始坏档**直接覆盖**，导致无法进行后续人工修复。P1→P2 迁移原先即使备份写入失败，也可能覆盖唯一的旧存档。多标签页旧版本也可能把更高 revision 覆盖为较低 revision。

本轮采用“**读取失败则保留原始字节、普通写入拒绝覆盖**”策略：

1. 无存档：正常生成并保存初始状态；合法 v2：正常恢复；损坏、超限或未知 schema：生成**仅供当前会话试玩**的临时初始状态，返回 `blocked:true` 和原因，`saveLocal()` 拒绝覆盖原始值。
2. P1 迁移：先确保 `backup-v1` 存在且与旧存档**字节完全一致**，再允许替换为 P2；备份失败或已有备份不匹配时，升级结果仅在内存中使用，原始 P1 字节保持不变。
3. 写入：读取并校验现有存档；当现有存档损坏、当前 revision 高于待保存 revision、旧存档备份不匹配或浏览器拒绝存储时，返回 `false`。仅在用户点击并确认**重置**后使用 `allowReset:true` 覆盖旧值。
4. UI：异常状态显示持续性的本地保存警告；确认重置前提示原始数据可能仍可人工修复，重置会覆盖这些字节。存储事件带来的异常同样不会触发自动覆盖。
5. 限制读取/写入的存档字符串最大长度为 160,000 个 UTF-16 代码单元（约束恶意大对象；并非网络传输字节数）。

## 自动化测试

新增 `tests/merge-storage-safety.test.mjs`，覆盖 13 个用例：损坏 JSON、结构错误、重复 ID、非法余额、超长输入、明确重置、旧标签回滚、正常保存、迁移成功、备份拒绝、备份不匹配、迁移写入失败、存储异常。执行：

```sh
node --test tests/merge-*.test.mjs
bash scripts/security-check.sh
```

## 剩余风险 / 上线前必须完成

- P2 localStorage 的“读取 → 比较 revision → 写入”**不是跨标签原子事务**。本轮只能拦截已经存在的较新 revision，无法保证两个标签完全同时写入时不丢失更新；正式云存档必须依靠服务端事务 CAS 与幂等操作 ID。
- 本地存档仍可被浏览器开发者工具手工伪造，**不得导入正式云端经济账本**。
- 失败保护不会自动修复已损坏的 JSON；必须由用户自行确认重置或后续单独开发恢复/导出工具。
- 浏览器无痕模式、存储配额、移动端 Safari/微信 WebView 和双标签实机尚未做端到端测试。
- `saveLocal()` 不能阻止其他未使用本模块的脚本直接改写相同 localStorage key。
