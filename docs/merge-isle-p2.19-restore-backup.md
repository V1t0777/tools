# 《云屿百物铺》P2.19 — 普通模式恢复前独立原始备份保留（未发布）

新增 `merge/save-restore-backup.mjs`：在 P2.18 只读导入预检通过后，将现有普通模式存档原文逐字保留在独立键 `toolbox.merge-isle.local.v1.restore-backup-v3`。没有原存档则无需备份。**本轮不实现导入、覆盖、删除、云端同步或界面入口。**

保护措施：要求调用方提供准确的 `expectedRaw`，预检及备份前后反复核对；已有备份与当前原文不同时拒绝写入，不能清空旧备份；写入后必须读回相等，主存档发生变化则报告失败。配额错误、存储异常、读回损坏均失败关闭。结果冻结、脱敏，不暴露游戏经济和存档内容。剧情模式键完全不读取或修改。

限制：浏览器 `localStorage` 的读/写**不是原子事务**，双标签在最终检查与写入之间仍存在竞争窗口；此实现不能提供真正 CAS 或事务回滚。独立备份键仍与主存档同属本地站点数据，清理浏览器数据可同时丢失二者；已有不一致备份必须人工处理，不得自动覆盖。正式导入还需要明确用户确认、重新预检、可靠原始备份、写入后校验、失败保护与移动端实机测试。

专项测试：`tests/merge-save-restore-backup.test.mjs`。验收要求最新 SHA 对应全仓库 Node 回归、静态安全/部署隔离、完整 Git 历史密钥扫描三项均成功。仅保留在 Draft PR #58，禁止修改 main、合并、发布 GitHub Pages/Cloudflare/Edge、线上 Supabase 操作及作弊后门。
