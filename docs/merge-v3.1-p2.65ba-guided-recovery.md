# P2.65ba｜满盘解困连续操作发行回归（未发布）

## 目标与范围
2026-10-29。普通经营模式现有「整理提示」必须对应可实际完成的引擎操作，而不是仅返回理论上的“可恢复”。本轮不改经济数值、存档格式或新增自动救援；只验证真实引擎与已接线页面入口的完整连续操作。

## 新增验证
1. 56 格满盘、4 格仓库满仓、金币和等级足够：提示扩容 → 真实扣费 50 金币 → 仓库扩至 6 格 → 再提示收纳 → 实际腾出棋盘空格；验证材料 ID 集合不变、revision 恰好 +2。
2. 满盘且仓库中有委托材料：先收纳一件材料 → 取出仓库订单材料 → 交付委托；验证只消耗交单材料、奖励严格来自真实订单、revision 恰好 +3。
3. 满盘且满仓但存在合法合成：先合成两件低阶材料 → 交付合成产物；验证棋盘释放两格、没有额外金币或材料。
4. 真实普通页面 DOM 入口：用户点击整理提示 → 仓库升级 → 再次整理提示 → 选中棋盘材料 → 收纳；验证按钮可用、存档写入与剧情存档隔离。

以上测试均使用真实引擎状态转换，不直接向结果中注入资源；只读提示不会自动写入。故障状态仍应保留存档，不允许自动重置。
