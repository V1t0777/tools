## 本轮自动化证据范围
- 使用真实 Chromium 页面及 CDP touchStart/touchMove/touchEnd，从棋盘格开始纵向滑动，必须推动整个文档纵向滚动，不得误触发横向棋盘滚动。

本轮仅增加普通模式测试和中文验证说明，不更改正式运行时、经济数值、剧情源文件、main、导航、部署白名单、云服务或线上数据。PR #58/#59 继续 Open/Draft，禁止发布。只有最终 SHA 的 Node 全回归、security-check.sh/部署隔离及全历史密钥扫描均通过，才可称自动化门禁通过。
