# 《云屿百物铺》V3 · P2.37 异常重置前备份可导出性门禁（未发布）

## 风险与范围
P2.35 的异常重置备份仅按 JavaScript 字符单位长度检查 2,000,000 上限；P2.33/P2.34/P2.36 的实际导出则按 UTF-8 字节数以及异常 UTF-16 代理项 JSON 封装后的体积检查。因此中文大字符串或异常代理项可以先通过浏览器内备份、允许重置，却在事后无法通过现有导出功能下载。

## 单一工程修复
- `merge/reset-backup.mjs` 在任何备份写入前，用只返回可信 `expectedRaw` 的只读存储视图调用现有 `prepareLocalSaveExport`，复用其 UTF-8/封装体积与编码器检查。
- 导出预算超限统一拒绝为 `BACKUP_TOO_LARGE`；编码器不可用拒绝为 `BACKUP_ENCODING_UNAVAILABLE`。失败时不写备份、不授权异常重置。
- 原有 `SAVE_KEY` 精确比较、备份槽冲突保护、写入后精确读回均保留。未改普通正常存档重置路径，也未读取剧情模式键。
- `tests/merge-reset-backup.test.mjs` 增加中文 UTF-8 超限、异常 UTF-16 封装超限、合法异常字符备份与编码器不可用四项回归。

## 验证边界
这只保证异常重置前备份**符合现有导出器的编码和文件大小预算**，并不保证 iPhone Safari/微信 WebView 实际完成文件下载。浏览器内备份仍可能随网站数据清理一起丢失；真实跨标签竞争仍未获得 Web Locks 原子保障。没有实现恢复、云存档、数据库操作或发布。
