# 云屿 V3.1 · P2.65aa 原生文件选择器返回授权收口（2026-10-28）

## P0 发行风险
P2.65z 的 15 秒孤立选择器恢复仅凭 focus 即可开始计时。浏览器可能在文件选择器仍然打开时触发额外 focus；若用户选择文件较慢，旧计时器可能提前清除有效选择器，导致迟到的 change 被拒绝。此为移动端导入可用性问题，不应靠缩短宽限期处理。

## 本轮变更
- 统一生命周期桥接器增加可选同步 onBlur，只有窗口确实 blur 或选择器经历过 document.hidden，后续已核验的 focus/可见恢复才可开始宽限期。
- 每个选择器最多安排一次宽限计时；重复 focus 不得缩短期限，旧选择器的计时器仍不能释放新选择器。
- 过期选择器迟到的文件 change 继续拒绝，不读取、不写普通档、不占用恢复前备份槽。有效重新选择仍允许导入。
- 保持 15 秒宽限、Web Locks 锁内授权、BFCache 和剧情存档隔离；不增加云端服务、正式导航或部署内容。

## 验证
- 新增真实普通页面入口 DOM 测试：无 blur 的额外 focus 不触发恢复；重复 focus 不缩短宽限；过期文件拒绝、重新选择可用。
- 生命周期桥接测试：blur 同步只读，detach 后不再触发回调。
- 调整 P2.65z 三项既有测试，显式模拟原生选择器 blur→focus 返回；保留原有安全断言。
- **最终全仓库 Node、security-check.sh、完整历史密钥扫描以新 HEAD 的 GitHub Actions 实际结果为准，未通过前不得宣称完成。**

## 仍未验证
Safari/微信原生文件选择器是否产生 blur 或 visibilitychange 因系统版本而异；两者均缺失时仍采取安全拒绝并提示重开页面，不冒称已完成真机验收。下载落盘、双标签实际浏览器与 Cloudflare 后台部署状态均待独立核实。PR #58/#59 保持 Open/Draft，不发布。
