# 《云屿百物铺》V3 · P2.40 跨标签同步取消过期拖拽（未发布）

## 问题与修复

普通模式在接纳其他标签页的有效存档时，会替换棋盘和当前状态，但 P2.39 以前未取消正在进行的拖拽手势。旧手势可能持有旧棋盘格子的索引和悬浮图标；远端状态采用后，迟到的 pointerup / click 有机会错误操作新棋盘，或留下旧拖拽图标。

本轮仅在**确实接纳不同原始字节的远端存档**时，先移除旧拖拽 ghost 并清空 drag，再设置 ignoreNextClick，阻止延迟到达的合成点击。若原始字节未变化或事件无关，保持当前手势不受影响。保留原有 revision、经济状态、时间进展、storageArea 来源校验与只读跨标签同步策略。

## 测试与风险

`tests/merge-storage-event-policy.test.mjs` 使用 Node VM 执行实际 storage 回调，验证已接纳远端存档时取消旧拖拽并抑制旧点击，以及无关/未变化事件不取消拖拽。仍需真实浏览器双标签、触摸手势与 iPhone Safari/微信 WebView 验收。若远端同步使 pointerup 丢失，首次后续正常点击可能被保守忽略一次，优先避免错误合成。

此增量不引入 Web Locks，不能消除同步 localStorage 的跨标签写入竞争；无云存档、线上数据库或部署变更。必须以**本次 HEAD** 的全仓库回归、静态安全/部署隔离和完整 Git 历史密钥扫描全部成功为工程完成条件。

PR #58/#59 保持 Open/Draft；不修改 main、不合并、不发布、不调整部署白名单、不执行线上 Supabase SQL、不制作美术、不实现作弊后门。
