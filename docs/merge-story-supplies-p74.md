# P74 · 剧情工作台补给闭环（2026-10-27，未发布）

## 实际功能
原引擎已具备四种补给道具、一次性成就奖励和限量金币商店，但剧情工作台没有入口，玩家在首卷经营时无法主动使用体力恢复和工坊冷却卡。本轮仅将既有离线补给规则接入剧情工作台 UI，**没有新增奖励、改变价格、补货上限或体力公式**。

- 体力：背包显示汽水、便当库存，未满体力时可消耗；所有效果由原有 `useSupply` 决定。
- 冷却：仅列出当前正在冷却的剧情工坊，按目标分别使用加速卡或重启卡，不会影响其他生产器。
- 商店：显示四种补给的既有价格与剩余终身限购次数；金币不足或售罄时禁用。提示购买可能延后剧情建筑建设。
- 安全：全部按钮使用工作台既有 render generation 防重放、原文字节预检、Web Locks/CAS 写入及写后双重复核。只写 `STORY_WORKSHOP_KEY`，不读取或修改普通模式存档/商店。手机优先 48px 触控、窄屏单列/双列、深色模式和减少动画。

## 自动化
`node --test tests/merge-story-supplies-dom-p74.test.mjs`：真实工作台模块级 DOM 测试覆盖购买+使用、旧按钮防重复、真实生产器冷却卡、锁失败不写入、终身限购持久化。仍需执行仓库全套 Node、`bash scripts/security-check.sh` 与完整历史密钥扫描；以最终提交 SHA 的 GitHub Actions 结果为准。
