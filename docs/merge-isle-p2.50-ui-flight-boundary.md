# 《云屿百物铺》V3 · P2.50 异步页面单飞保护（未接入、未发布）

## 背景
P2.45–P2.49 已分别建立普通模式的独占锁、游戏动作、计时器、重置和启动持锁事务边界，但当前 `merge/main.mjs` 仍是同步 `persist()`。直接把某个点击回调改为 `async`，会产生连续点击、旧拖拽、异步保存完成前误发布状态等风险。禁止只接入部分写入入口。

## 本轮单一增量
新增 `merge/normal-ui-flight.mjs`，为后续页面整体切换准备不排队的单飞控制。一个异步保存未结束时第二次操作立即拒绝；外部存储冲突、页面隐藏或重置尝试可调用 `invalidate()` 使在途结果不能更新 UI。仅接收带有原始字节、状态及写后读回证明的事务回执；无变化的持锁计时器、持锁启动验证也有明确白名单。事务抛错、回执不可信、发布回调抛错均释放忙碌标志。

本模块**不执行存档写入、锁请求或 UI 渲染**，只为真实持锁事务提供页面层的单飞与结果发布门禁。即使已写入的事务被失效标记挡住，不能推断写入已回滚；页面必须阻断继续操作并重新核对真实存档。

## 专项回归
`node --test tests/merge-normal-ui-flight.test.mjs`：延迟回执、重复点击拒绝、冲突失效、异常事务、未验证回执、时钟与启动回执、发布异常及非法参数。
