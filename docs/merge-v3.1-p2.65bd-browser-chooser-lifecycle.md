# P2.65bd · 普通经营模式文件选择与后台触控恢复门禁（2026-10-29）

## 目的与实际改动

本轮聚焦两个同属移动浏览器页面生命周期的发行风险，不修改游戏经济、存档格式或运行时。

1. 在真实 Chromium 页面打开普通模式导入文件选择器后，尝试点击“重置试玩进度”和“导出原始存档”。验证待选择文件期间不弹出破坏性重置确认、不下载可能过期的存档、不改变当前存档和恢复前备份的**原始字节**；取消选择后应解除等待。测试只替代原生系统选择器的弹出，仍执行页面按钮、localStorage 与运行时守卫。
2. 后台拖拽、另一标签写入、返回前台后的新生产器触控，不再依赖固定 140ms 睡眠推断命中区域已恢复，而是验证实际 elementFromPoint 命中生产器、页面可见且拖拽浮层已清空。恢复写入仍须严格为一次 revision 增量和一次体力消耗；超时保留失败，并记录既有脱敏状态快照。

## 验证边界与风险

本轮测试仍使用真实 Chromium 与 CDP 模拟触摸，**不是** iPhone Safari 或微信 WebView 的原生文件选择、下载落盘、物理触控测试。不能以单次通过宣称历史间歇超时根因彻底消除；应继续观察后续多轮 CI，若失败需核对失败快照与真实运行时竞态。320px 极窄屏棋盘操作、真实 iPhone/微信文件选择及下载、剧情首卷集成仍是候选版验收阻塞。
