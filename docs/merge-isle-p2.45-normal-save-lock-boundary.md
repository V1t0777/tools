# 《云屿百物铺》V3 · P2.45 普通模式写入锁边界（未发布）

## 范围与动机
普通模式当前使用同步 localStorage，即使逐字节检查基线，两个标签页仍可能同时读取同一版本并先后覆盖。P2.45 新增**独立、未接入页面**的 merge/normal-save-lock.mjs，为下一阶段迁移实际写入入口提供可验证的 Web Locks 独占边界；本轮不宣称修复了当前试玩页面的并发覆盖。

## 安全契约
- 锁名固定为 toolbox.merge-isle.normal-save.write-v1，仅在真实独占锁回调内执行事务，ifAvailable:true 避免把过期游戏操作排队到未来执行。
- 无 Web Locks、锁被占用、锁名/模式不符、请求异常、回调异常、收据不符合约定时均拒绝；绝不使用 localStorage 自旋锁降级。
- 回调必须在持锁期间重新读取当前原始存档、校验基线并完成写入及读回验证；仅取得锁本身不证明数据持久化。
- merge/cloud/tab-coordinator.mjs 的云队列锁属于不同资源，不能代替普通模式写入锁。
