# P2.65bj｜离线标签跨标签进度一致性与 iPhone/微信验收清单（2026-10-29）

## 发行目标与自动化证据

首发只包含**已加载的离线单机 Web 普通经营**及另行集成的首卷剧情必要闭环，不承诺断网首次打开、PWA 安装或云存档。此轮在现有 Chromium 双标签、Web Locks、BFCache、重置/导入导出和离线生产测试后补充：

1. 先在在线状态重新加载观察者标签 A，确认其从持久化存档启动。
2. 仅对 A 施加 CDP offline；标签 B 保持正常网络并通过真实生产器写入一次。
3. A 重新前台时仍须 `navigator.onLine === false`，但应从同源 localStorage 读取 B 的**精确原始字节**，显示最新体力；不得回滚、重复写入或改动恢复前备份。
4. A 离线导出只允许提示“已请求下载，请核实文件已保存”，不得冒充落盘。既有独立下载目录验证仍是 Chromium 的文件落盘证据。
5. 结束时恢复网络模拟；即使测试异常也必须清除 offline 设置。

**通过条件：** 自动化 Node/Chromium 专项、`bash scripts/security-check.sh`、静态部署隔离和完整 Git 历史密钥扫描在最终 SHA 全部通过。CI 仅证明 Chromium 行为，不等于 iPhone Safari/微信 WebView。
