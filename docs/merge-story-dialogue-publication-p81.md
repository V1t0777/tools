# 《云屿百物铺》剧情 P81｜对白保存后发布核验（未发布）

## 发现与修复
剧情对白的 Web Lock 回调可能已成功写入，但另一个标签在锁释放后、当前页面从 await 恢复前替换了存档。旧 UI 直接把内存进度标记为“已保存”，造成误导，甚至继续提供旧剧情入口。

本轮新增只读发布核验：成功写入后先对比故事键的精确原文字节、生命周期 epoch 和页面可见状态；渲染后再次核对。并发相同每日事件固定的采纳路径同样在渲染后核验。失败则显示冲突、停止后续旧页面写入，不自动重试、不删除或覆盖任何存档。

## 自动化专项
- 完整原文字节匹配、并发替换、epoch 失效、后台暂停、存储异常的门禁测试。
- 真实剧情 UI 模块 DOM 故障注入：模拟 Web Lock 返回后另一标签替换重置结果，验证页面拒绝“已保存”；无并发时合法重置正常完成。
- 普通模式与剧情工作台的两个独立存档键保持原样。测试与安全门禁以最终新 SHA GitHub Actions 为准。

## 限制与发行边界
本修复缩短了错误成功提示窗口，但 localStorage 仍不具备跨标签原子事务，浏览器事件和后台恢复可能继续存在竞态。真实 iPhone Safari、微信 WebView、Windows 手工、异常存档下载落盘仍是发行阻塞。不得把 Node/CI 视为真机验收。
