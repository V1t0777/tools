# P2.65bv — 真正 BFCache 返回后的旧持久按钮触控失效（未发布）

## 范围
本轮仅扩展普通模式真实 Chromium 浏览器回归，未改游戏运行时、经济、存档格式、剧情文件、部署配置或正式导航。

## 真实浏览器验证
1. 在正常经营标签 A 的重置及导出按钮分别触发触摸 pointerdown，不发送 click。
2. 真实导航离开，再用浏览器历史记录返回；要求 `pageshow.persisted === true`，不允许以模拟 pageshow 冒充 BFCache。
3. 对同一 DOM 按钮发送旧触摸兼容 click：重置不得弹确认，导出不得调用下载链接，存档原始字节不得变化。
4. 新触摸重新点击重置必须进入新的确认（测试拒绝），原始字节仍不变。
5. 新触摸重新点击导出必须经真实 Chromium 下载文件，并与当前普通模式存档结构一致；既有双标签/Web Locks、导入、备份和经济测试继续运行。

测试只控制触摸事件时序及重置确认拒绝；页面导航、BFCache、存储、下载、运行时均使用真实 Chromium。该测试不替代 iPhone Safari/微信 WebView 的原生文件选择、落盘及后台恢复验收。

PR #58/#59 必须 Open/Draft；不合并 main、不发布 Pages/Cloudflare/Edge、不更新白名单或导航、不操作线上 Supabase、不引入作弊入口。提交标题保留 `[CF-Pages-Skip]`。真实 iPhone/微信、剧情首卷集成、经济多种子与 Cloudflare 后台部署状态仍需独立验证。仅在新 HEAD 的全仓库 Node、静态安全/部署隔离及完整历史密钥扫描全部通过后，才可记录 CI 通过。
