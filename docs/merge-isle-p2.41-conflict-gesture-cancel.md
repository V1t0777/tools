# 《云屿百物铺》V3 · P2.41 跨标签冲突取消旧拖拽（未发布）

## 问题与范围

P2.40 已在**成功接纳**远端存档时取消旧棋盘拖拽，但遇到远端存档损坏/被删除、已有保存阻塞、较旧修订号、同修订号经济分歧时，storage 回调会提前返回。此时旧手势的 ghost 和 pointerup 仍可能存在；虽然保存会保守拒绝，页面却可能继续响应旧手势并显示误导性的拖拽反馈。

## 本轮改动

仅修改 `merge/main.mjs` 的普通模式 storage 事件路径：集中使用 `cancelStaleGesture()`，在上述四种冲突/异常路径和原有成功接纳路径清理 drag/ghost，并抑制可能迟到的一次合成 click。保持旧的 `state`、`persistedRaw`、冲突原因及原有状态文案不变；不在事件中读写其他存储键，不尝试自动冲突合并。

`tests/merge-storage-event-policy.test.mjs` 用 Node VM 执行实际事件回调，验证四种异常分支均取消手势、不发布远端棋盘、不写存档；更新既有 VM fixture 的拖拽上下文。P2.40 的无关事件、原始数据未变事件仍保留原有不取消手势回归。

## 验证边界与剩余风险

Node VM 仅验证回调代码，不等于真实浏览器双标签、iPhone Safari 或微信 WebView 触摸验收。首次后续 click 可能被保守忽略一次。同步 localStorage 仍非原子事务；Web Locks 与实际游戏操作的异步接入仍待后续单独推进。

本轮只修改独立分支及专项测试、中文文档，不触碰 main、正式导航、部署白名单、线上 Supabase、云存档或美术。PR #58/#59 必须保持 Open/Draft；本次 HEAD 对应的全仓库回归、静态安全/部署隔离及完整 Git 历史密钥扫描全部成功后才能标记工程完成。
