# 《云屿百物铺》V3.1 · P2.65i 普通模式本地导入闭环

范围：PR #58 独立普通经营模式，不修改共享 HTML/CSS 或 story 源文件；PR #59 独立开发。

## 本轮 P0 改进
1. 在现有普通模式「导出原始存档」旁由 JS 添加「导入普通模式存档」和「导出恢复前备份」按钮，不更改正式导航与部署白名单。仅允许用户手动选择文件；不上传网络。
2. 读取文件前检查物理大小（2 MB 上限）；读取后检查字符串大小（160000 UTF-16 代码单元）、V3 普通模式结构与当前精确原始存档基线。只读预检拒绝剧情模式、旧版、异常或已存在文件。
3. 显式确认覆盖，降级恢复必须再次确认。文件读取、确认、BFCache/pagehide/隐藏态或跨标签变化后均核验原始基线；任何失败不得继续旧授权。真实写入仅调用既有 runtime.restore，共享 Web Locks、独立备份槽与读回验证；绝不无锁回退。
4. 导出恢复前备份只读 RESTORE_BACKUP_KEY，复用安全下载协调器。下载成功回执只表示请求发起，不表示 Safari/微信已保存文件。

## 验证与限制
新增独立导入流程测试（确认/降级/异步跨标签/页面切换/非法文件/忙状态）及实际页面 DOM 导入与取消测试。须以最新提交 SHA 对应的全仓库 Node、安全检查及历史密钥扫描为准，不能用旧 SHA 替代。尚需真实 iPhone Safari、微信 WebView、文件下载落盘和多标签浏览器验收；自动化 DOM 不等于真机。

风险：浏览器可能阻止文件选择/下载；localStorage 并非数据库级 CAS，非协作旧标签可在锁外写入；恢复前备份槽若已保留其他原始字节，事务将拒绝覆盖并阻断继续恢复。失败时必须先导出当前与恢复前原始备份，不得清除数据或盲目重试。保持 PR #58/#59 Open/Draft，不合并、不发布、不改 main/线上 Supabase。
