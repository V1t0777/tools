# P94｜双模式往返与异常存档隔离回归（2026-10-28）

## 目标与范围

本轮将普通经营 P2.65ab/ac 的文件选择器取消与 BFCache 生命周期重入保护安全前向同步至剧情分支，**不改动普通经营实现**。新增三个纯离线 Node 回归，模拟普通模式、剧情对白、剧情工作台三个独立持久化键的往返读取与异常恢复。

- 正常往返：两个经济引擎各自执行一次真实仓库收纳，剧情对白推进一次，反复读取三个键，核对状态、原始字节和写入目标。
- 单侧损坏：普通模式记录损坏后剧情仍可推进；剧情对白记录损坏后普通模式仍可操作；任何一侧不得静默覆盖另一侧异常原文。
- 旧标签页：普通模式与剧情对白各自发生对端更新后，旧基线的 CAS 写入都必须拒绝，不能回滚新进度。

运行专项测试：`node --test tests/merge-story-mode-roundtrip-p94.test.mjs`。完整安全门禁按 `AGENTS.md` 执行 `bash scripts/security-check.sh`，以新 SHA 的 GitHub Actions 三项结果为准。
