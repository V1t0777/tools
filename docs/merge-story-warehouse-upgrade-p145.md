# P145｜剧情仓库付费扩容闭环（2026-10-30，未发布）

## 缺陷与修复
P142 已识别「满盘、满仓且无可交付/合成材料，但可合法付费扩容」的恢复路径，却仅显示文字提示；剧情工作台并无实际扩容按钮，玩家无法执行该建议。这是 P1 卡关恢复缺口。

本轮在剧情临时仓库增加明确的「扩容仓库至 N 格 · ◈费用」按钮及等级、金币、满级提示。操作只调用既有 `upgradeWarehouse` 引擎规则，沿用剧情独立存档的 Web Locks、原始字节 CAS、revision 和写入后验证；不会触及普通模式存档、赠送资源或绕过限额。按钮沿用 ≥48px 触控目标与 BFCache/旧手势防护。

若扩容会使已经攒够的下一处首卷建筑金币不足，必须再次经用户原生确认；确认后重读原始存档，拒绝跨标签变更和后台暂停。确认不是锁，真正写入仍由 `commit()` 的锁及存档校验执行。

## 专项回归
`node --test tests/merge-story-warehouse-upgrade-p145.test.mjs` 覆盖：真实 UI 点击扩容与付费、同一存档收纳/生产恢复、普通/剧情对白隔离、建筑预算取消、确认对话框期间他标签更换存档、等级与金币禁用、移动触控结构。最终完整 Node/静态安全/全历史扫描以此 SHA 的 GitHub Actions 为准。

## 未消除风险
`localStorage` 并非跨标签原子事务；Web Locks 不可用或被绕过时仍存在平台限制。桌面 DOM/Chromium 自动化不等于 iPhone Safari、微信 WebView 实机触控、离线重启或损坏证据文件真正落盘。若 CI 有任何失败，不得把本轮记为验收通过。PR #58/#59 保持 Draft，禁止部署、合并 main 或触碰线上 Supabase。
