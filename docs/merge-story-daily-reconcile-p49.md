# 《云屿百物铺》P49 · 双标签同日事件相同固定结果的安全只读接纳

## 问题与范围
P47/P48 已把每日事件固定写入剧情存档，且拒绝跨午夜和过期写入。但两个标签从同一原始存档并发固定同一天、同一个确定性事件时，第二个标签即使只是重复写入相同结果，也会进入 WRITE_CONFLICT 只读阻断。此次仅消除**已证实完全相同的同日固定结果**造成的误阻断，不做一般性的存档自动合并。

## 实现
- 新增 `merge/story/daily-pin-reconcile.mjs`：从原始字节解析、校验基线，重新计算该日应写入的固定结果；只有实际存储字节与计算结果、原本计划写入的字节**三者完全一致**才返回 true。
- `merge/story/ui.mjs`：仅当同日、锁调用正常返回但写入因基线变化被拒、页面未处于存储损坏/不可用状态时，再读取一次当前存档。若精确验证为另一标签已经完成同一固定，则只读接纳当前存档，不再写入、不重新抽取事件、不清除其他冲突。
- 跨午夜仍沿用 P48 的无写入取消路径；其他章节写入、人物选择变化、DLC 变化、损坏存档、日期变更、Web Locks 异常仍拒绝接纳。原存档格式、经济资源、部署结构均不变。
- 新增 `tests/merge-story-daily-reconcile-p49.test.mjs` 六项专项测试：真实锁队列下的重复固定、章节竞争、日期/提议/序列化不一致、异常存储、其他选择变化、UI 安全契约。
