# 云屿 P103｜首卷剧情工作台下一步导航与上游安全同步（未发布）

## 可见行为
剧情工作台顶部新增只读「首卷下一步」提示。基于当前剧情对白存档与独立工作台存档，显示真正待完成的第一单、花园、港湾或门面目标，点击仅滚动到本页对应经营区域。经营目标已满足时，提供返回剧情页下一幕的链接；四章完成后返回结局/人物支线。缺失首卷存档时引导先开启剧情，任一存档损坏或不可读时停止提供可能误导的进度链接。

实现复用 `nextCoreStoryJourney`、既有五处经营门槛与已验证的核心故事包；不增加解锁、奖励、消费、跨模式共享、存档格式或 DLC 路由。链接只是导航，剧情页和工作台的实际写入继续执行原有 Web Lock、原始字节、生命周期和剧情前置条件核对。页面暂停或保存中隐藏导航动作。

## 验证
`node --test tests/merge-story-workshop-next-step-p103.test.mjs`：真实 7×8 引擎种子 42 的四项经营里程碑，十二幕故事与每一阶段的「继续经营 / 返回阅读」转换；缺失或损坏存档安全降级；移动页面的可访问只读导航契约。该测试不是实际 iPhone/微信 WebView 的触控或手工通关。

同步普通模式 P2.65al 前已对照双方共同祖先和三处上游文件 Blob，剧情分支对上游修改路径无独立变更；采用双父提交，不覆盖并行代码。最终完整 Node、静态安全与部署隔离、完整 Git 历史密钥扫描须以新 SHA GitHub Actions 实际结果为准。
