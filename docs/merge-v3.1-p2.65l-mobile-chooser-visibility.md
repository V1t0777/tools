# 《云屿百物铺》V3.1 · P2.65l 原生文件选择器隐藏态恢复（未发布）

范围：仅 Draft PR #58 普通模式页面、实际页面 DOM 回归和本说明；不修改剧情源文件、main、正式导航、部署白名单或线上数据。

## P0 场景与安全边界

部分 iPhone Safari / WebView 在打开原生文件选择器时可能触发 `visibilitychange(hidden)`，但不一定触发 `pagehide`。原 P2.65j 逻辑会直接清除文件选择授权，导致用户选择正常 JSON 后也只能重复点击导入，构成移动端可用性风险。

本轮只允许**已经由用户点击打开**的文件选择器经历一次「hidden → visible」且**没有 pagehide** 的往返。原有 importEpoch 仍在隐藏时递增，其他已开始的异步文件读取、重置确认、恢复授权全部失效；仅保留尚未返回的选择器票据（原始 raw、epoch、一次隐藏标志）。文件 change 必须发生在页面恢复可见、运行时已核验、原始 raw 未变化时；随后仍走文件大小/结构预检、明确确认、降级二次确认、Web Locks、原始备份及读回核验。连续两次隐藏、任何 pagehide/BFCache、取消、第二次点击重入均不能复用旧票据。

新增四项真实 HTML 入口 DOM 模拟测试：单次原生选择器隐藏往返允许安全导入；期间跨标签改档拒绝；pagehide/重复隐藏拒绝；重复点击不能替换未完成选择器。现有 BFCache、取消和异步读取期间隐藏拒绝测试仍需全仓回归。

## 未消除的风险

真实 iPhone Safari/微信 WebView 的文件选择事件顺序尚未实机测量。如果 `change` 在仍为 hidden 时到达，本轮依旧拒绝，不缓存文件或后台写入；此路径仍可能需要下一轮真机驱动修复。真实下载落盘、双标签及 Cloudflare Pages 部署记录仍需独立核验。不得以 Node/CI 结果冒充真机通过或 RC。

必须使用**本轮新 SHA** 的全仓库 Node 回归、`bash scripts/security-check.sh`/部署隔离、完整历史密钥扫描三项结果验证；未全绿不能标记完成。保持 PR #58/#59 Open/Draft，不合并、不部署、不发布。
