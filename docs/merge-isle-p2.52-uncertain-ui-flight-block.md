# 《云屿百物铺》V3 · P2.52 异步事务不确定结果永久阻断（未接入、未发布）

## 发现的问题
P2.50/P2.51 的单飞门禁虽支持外部调用 `block()`，但 `run()` 遇到保存结果不确定、原始存档过期、事务抛错或发布回调失败时，默认只返回错误，不会主动永久阻断。页面接入时若遗漏调用 `block()`，可能继续用旧内存状态发起下一次写入。尤其发布回调抛错时，存档可能已经保存成功，不能将其视作普通可重试操作。

## 本轮安全增量
在 `merge/normal-ui-flight.mjs` 内为 `run()` 增加失败分类：
- 仅对**已知在写入前拒绝**的原因（如 `ACTION_REJECTED`、`SAVE_LOCK_BUSY`、`WEB_LOCKS_UNAVAILABLE`、未确认重置、无效时钟/动作/参数）保留重试可能性；这些返回不自动永久阻断，但也不会绕过持锁要求。
- 对 `STALE_BASELINE`、写后读回失败、存档不确定、未知错误、事务抛错、无法验证的成功回执和发布回调抛错，自动永久 `block()`。在途结果仍受 epoch 检查，不得发布旧状态。
- 保留原有 `block()` 幂等行为；没有 `unblock()`，必须重新打开页面并重新校验真实存档。此策略宁可要求用户重载，也不猜测写入是否发生。
- 不更改存档格式、锁名、经济规则、剧情模式、导航、线上服务或现有页面入口。

## 专项回归
更新 `tests/merge-normal-ui-flight.test.mjs`：检查各种不确定失败均自动阻断；明确无写入的拒绝仍可重试；异常成功回执不能发布；发布异常及事务异常均不能继续操作。运行 `node --test tests/merge-normal-ui-flight.test.mjs`，再以**新提交 HEAD** 对应的全仓库回归、静态安全与部署隔离、完整 Git 历史密钥扫描为验收依据。

## 重要限制
当前 `merge/main.mjs` 仍使用同步 `persist()`，本轮没有接入实际页面；不能宣称跨标签原子写入或真实浏览器验证完成。后续需统一切换启动迁移、游戏动作、计时器、确认重置、异常备份，并处理移动端异步交互与跨标签 storage 事件。PR #58/#59 保持 Open/Draft；禁止发布、合并、线上 Supabase 操作及调整其他自动化任务。
