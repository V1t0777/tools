# P2.65bb｜资源不足、工坊冷却与低效率经营的离线发行回归（未发布）

## 本轮目标与变更边界
2026-10-29，北京时间。普通经营模式的“暂时等待”必须与“永久无合法操作”区分，体力和工坊充能不得被错误跳过；金币不足时不得免费购买补给。本轮仅新增真实引擎专项回归，不修改游戏经济、体力恢复速度、生产概率、道具库存、存档格式、UI 或剧情源文件。

## 五项可执行验证
1. **体力为零**：保留合法生产器并移除无关材料；确认整理提示为等待，恢复时间前生产被拒绝，恰好经过 180 秒后获得 1 点体力，随后生产一次仅增加 1 个材料、1 个 revision，消耗 1 点体力，无额外金币/经验。
2. **所有生产器冷却**：设置三个工坊合法的 0 充能、45 秒冷却状态；冷却结束前禁止生产，结束时 12 次充能恢复但不增加体力、金币或 revision；玩家主动生产才写入一次。
3. **体力与冷却同时耗尽**：工坊在 45 秒后恢复不意味着体力同时恢复；仍须等待独立的 180 秒体力计时，避免将冷却误判为“已解困”。
4. **金币和补给不足**：零金币购买汽水与零库存使用汽水均必须失败，原始存档字节、购买计数、背包、revision 不变；不得因引导提示而赠送资源。
5. **90 日低效率多种子**：2 个固定种子 × 2 种行为 × 2 种花钱策略，共 8 条真实经营引擎轨迹，每日一次、每次 5 分钟；检查金币收支守恒、棋盘与仓库容量边界、行为停滞与规则死局分类计数。此为人工策略压力测试，不能代表真实玩家通关时长或长期留存。
