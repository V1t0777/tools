# P153 · 一次性日常线索当日回看修复（2026-10-30，未发布）

## 缺陷与修复
首卷特殊事件「潮水送来的木箱」为一次性线索，首次阅读后会进入已完成记录。原日常事件选择器只从“尚未完成或可重复”的候选列表查找当日固定事件，导致玩家**同一天读完木箱后**，原本合法的固定事件被误判为不可用；今日事件入口提示记录冲突，无法回看。

本轮仅修复 `merge/story/runtime.mjs` 的固定事件解析：优先匹配正常可用候选；当固定 ID 不在候选列表时，只允许**同一剧情包内已完成、不可重复、前置主线仍满足**的一次性事件以原对象只读回看。未知 ID、未完成的一次性事件、错误类型及前置条件不满足的记录继续返回空，不自动重抽、写入、补发经济资源或更改日常固定规则。第二天仍从可用事件重新选择，已完成木箱不再出现。

## 自动化验证
`node --test tests/merge-story-oneoff-daily-p153.test.mjs` 检查：首次固定→完成→当日回看与幂等、隔日排除已完成木箱、异常固定 ID 与前置条件安全阻断。全仓库 Node、安全脚本、完整历史扫描均以**新 SHA 的 GitHub Actions**为准；自动化不等于 iPhone Safari/微信 WebView 实机。

仍缺 iPhone Safari、微信 WebView、Windows 离线及损坏存档文件实际落盘验收；跨标签/BFCache、普通模式触控偶发超时、PR #58 上游安全同步仍为风险。PR #59 继续 Open/Draft，禁止合并 main、发布 Pages/Cloudflare/Edge、修改正式入口或部署白名单、接触生产 Supabase。
