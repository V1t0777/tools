# 《云屿百物铺》V3 · P2.30 时钟恢复预算核验（未发布）

## 本轮修复

P2.29 的同修订号白名单尚未验证体力增长是否有足够恢复时间，且未严格核对生产器冷却结束时刻与充能上限。本轮在现有只读策略内增加确定性预算校验。

- 体力恢复按 ENERGY_REGEN_MS 计算可用的完整恢复周期；拒绝无时间依据的体力增加、过快增加及未满体力时的漏算周期。
- 生产器必须确实到期，且从零充能恢复到 PRODUCER_CHARGES 的准确上限；提前解锁或部分充能不再被视作合法同修订号时钟更新。
- 满体力时的 energyAt 不得无故前进，只有生产器到期并经过完整周期才允许变化。
- 保留 P2.29 测试，并新增恢复预算、冷却到期、满体力时钟三组专项回归。
