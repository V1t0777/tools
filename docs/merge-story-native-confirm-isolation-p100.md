## 目的与场景

移动浏览器的原生确认框可能让另一标签先写入存档，且旧页面不一定及时收到 StorageEvent。本轮用真实剧情对白/工作台入口的 Node DOM 故障注入验证：确认时另一标签替换**同一**存档键，必须拒绝过期重置；只更新**另一**剧情模式键，则允许当前键的合法重置，但不得覆盖另一键或普通模式存档。

## 未解除风险

`localStorage` 读写并非跨标签原子事务；不协作的旧标签仍可能竞争。Node 模拟的原生确认不等于真实 iPhone Safari/微信 WebView 的后台恢复、下载落盘和手工四章通关。保持 PR #58/#59 Draft；不合并 main、不改正式入口/部署白名单、不发布 Pages/Cloudflare/Edge、不执行线上 Supabase、不制作作弊入口。只有质量门禁及用户终审满足后，才可另行请求发布授权。
