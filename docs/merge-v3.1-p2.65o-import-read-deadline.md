# 《云屿百物铺》V3.1 · P2.65o 文件读取挂起的安全恢复（未发布）

## P0 缺陷与范围
iPhone Safari、微信 WebView 或其他移动浏览器可能在系统文件选择器返回后让 `File.text()` 长时间不完成。原页面导入流程一直等待该 Promise，`importBusy` 保持占用，用户即使取消或返回可见页面也无法再次导入，除非重新加载。此类挂起不代表存档已恢复。

本轮仅针对**普通模式页面已经接线的本地 JSON 导入**增加 45 秒有界文件读取；超时后安全退出导入流程，释放页面导入按钮。底层 `File.text()` 不一定能中断，但它迟到的结果已被单次 Promise 结算门禁丢弃，绝不执行预检、确认或存档写入。正常文件读取成功时清理超时计时器；计时器不可用时在读取前拒绝。若等待期间发生页面生命周期变化或跨标签存档改变，原有精确基线检查仍优先返回阻断原因。

## 测试证据
- 原生文件读取永不结算：模拟到期，验证未弹确认、未调用恢复、未写普通/剧情存档；随后迟到的文件内容不能重放恢复。
- 正常读取：确认超时计时器清理，迟到计时器不会重放事务。
- 计时器不可用：拒绝文件读取且不写存档。
- 读取挂起时页面生命周期改变：优先取消旧授权，绝不恢复。
- 提交后以**最新 HEAD** 的全仓库 Node、`bash scripts/security-check.sh` / 部署隔离、完整历史密钥扫描的实际 GitHub Actions 为准。CI 不能替代 iPhone Safari、微信 WebView、真实双标签与文件下载落盘验收。

## 安全边界
未修改剧情源文件、`main`、正式导航、部署白名单、Supabase 数据或任何部署配置。PR #58/#59 保持 Open/Draft；不发布、不合并、不制作作弊后门。Cloudflare Pages 实际后台部署状态若无法独立读取，必须保留未知风险。45 秒仅是故障恢复上限，浏览器后台冻结计时器时可能更久；超时不保证底层原生文件读取已被取消。
