# 《云屿百物铺》V3 · P2.44 重置确认后取消旧棋盘拖拽（未发布）

## 风险与范围
普通模式在确认重置时，旧棋盘上的 pointer 手势可能尚未结束（例如触屏多指操作、拖拽中通过键盘确认）。原有重置逻辑会重新生成棋盘，但未清理活动拖拽；迟到的 pointerup / 合成 click 可能引用重置前的槽位，意外操作新棋盘。

## 单一工程增量
- 玩家**确认**重置后、备份或持久化尝试前，若有活动拖拽则移除悬浮图标、清空 drag，并设置一次性点击抑制。
- 即使异常备份或存储写入失败，旧手势也不会继续悬空；取消确认则完全不触碰手势。
- 沿用 P2.42 的下一次真实主指针 pointerdown 解锁机制，不新增定时器。
- 不修改重置 CAS、备份可导出性、经济规则、普通/剧情模式隔离、部署配置或网络请求。

## 专项回归与限制
`tests/merge-storage-event-policy.test.mjs` 使用 Node VM 执行实际重置事件处理代码，检查成功重置、持久化失败及用户取消三种路径，并断言手势在任何存储写入前取消。仍须真实浏览器双标签、多指触控、iPhone Safari 和微信 WebView 验收。同步 localStorage 并非跨标签原子事务；Web Locks 实际保存路径接入仍需单独设计和验证。
