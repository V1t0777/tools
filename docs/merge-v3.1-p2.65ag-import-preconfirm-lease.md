# 云屿 V3.1 P2.65ag｜普通存档导入预检后确认许可复核

- 日期：2026-10-28（北京时间）。范围：Draft PR #58 离线普通经营模式；不涉及剧情源文件、云端服务或部署。
- 问题：文件读取完成后的第一次 `inspect()` 与只读 `previewNormalSaveImport()` 之间，后者的存储读取可能同步触发页面离开、取消或另一标签页更新。旧逻辑预检返回成功便立即打开破坏性恢复确认弹窗，虽然最终 Web Lock 内仍会拒绝过期写入，但确认文字引用了已失效的存档快照。
- 修复：预检成功后、首次 `window.confirm` 之前再次检查页面可见性、导入代次、取消信号、运行时状态、当前存档原始字节及只读重验。失败时不弹确认、不调用恢复。确认后的现有复核及独占锁下最终检查保持不变。
- 专项回归：预检读取同步触发 pagehide、返回旧字节但另一标签随即更换原始存档、预检读取触发 AbortSignal。三种情况均不得进入确认/恢复，也不得触碰剧情命名空间。
- 发行风险：浏览器原生文件选择、真实双标签、BFCache、Safari/微信下载落盘仍需真实设备验收。单次 localStorage 读取与浏览器原生确认不构成跨标签原子事务；最终写入必须继续使用统一 Web Lock 和原始字节校验。
- 验证边界：本提交仅在 GitHub Actions 对**最终 HEAD** 的全仓库 Node、`bash scripts/security-check.sh`/部署隔离及全历史密钥扫描全部成功后才可宣称自动化门禁通过；CI 不等于实机验收。
- 发行硬边界：保持 PR #58/#59 Open/Draft，不修改 main/正式导航/白名单，不发布 Pages/Cloudflare/Edge，不操作线上 Supabase，不添加作弊入口。
