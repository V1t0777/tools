# 云屿 V3.1 · P2.65t 恢复前备份下载反馈闭环（2026-10-28）

## 范围与问题

普通模式恢复前备份按钮已能只读导出历史字节，但过去对下载失败、超限、异常字符封装及临时链接清理失败的反馈过于笼统，容易让 iPhone/微信用户误以为已得到可直接导入的安全存档。本轮仅修复已接线的离线页面反馈，不改存档内容、导入事务、经济规则或云服务。

## 修改

- `merge/main-locked.mjs`：恢复前备份导出区分无备份、过大、编码不可用、浏览器下载不支持/未启动、过频；成功时区分有效历史存档、异常原文及 UTF-16 JSON 封装，提示必须检查文件实际落盘；延迟清理异常单独告知。
- `tests/merge-locked-page-dom.test.mjs`：真实普通页面入口 DOM 模拟三组回归，覆盖历史原字节、孤立代理项无损封装、无备份/超限/WebView 拒绝下载与剧情存档隔离。
- 所有导出保持只读：不写 `SAVE_KEY`、`RESTORE_BACKUP_KEY` 或剧情存档；不会自动恢复、重置或上传。

## 风险与门禁

自动化只证明浏览器端已请求锚点下载，不证明 iPhone Safari/微信 WebView 真正保存文件。仍需真机检查“文件”中存在、可读取、字节一致以及跨标签/后台场景。当前 PR #58/#59 必须保持 Open/Draft，不修改 main/导航/部署白名单，不部署 Pages/Cloudflare/Edge，不触碰线上 Supabase。新 SHA 的 Node、security-check.sh/部署隔离和完整历史密钥扫描须全部成功后才可称 CI 通过；Cloudflare 实际部署状态仍需独立核实。
