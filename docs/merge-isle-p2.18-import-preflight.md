# 《云屿百物铺》P2.18 — 普通模式备份文件导入前只读预检（未发布）

## 范围

新增 `merge/save-import-preflight.mjs` 中的 `previewNormalSaveImport(fileText, storage, {expectedRaw})`。它只分析候选文件与当前浏览器已观察的普通模式存档，不导入、不修复、不覆盖、不上传任何游戏进度。此阶段**未开放导入按钮**，不能称为已具备备份恢复能力。

## 预检行为

- 只接受文本、在 V3 本地存档大小预算内且 JSON 可解析的文件；拒绝未知版本、剧情模式文件、伪造或损坏的普通模式存档。严禁把异常原始文本自动视为有效备份。
- `expectedRaw` 必须是调用方此前观察到的准确原始内容（`null` 表示确定无记录）。如普通模式存档在两个时刻之间变化，拒绝预检，避免静默覆盖其他标签页进度。
- 如原有存档损坏、版本不可识别或超限，先阻断恢复流程并提示另行保护原始字节，不能由候选导入自动清理。
- 若候选文件早于当前本地版本，以 `wouldDecreaseRevision` 标注可能的进度回退；结果中不包含货币、背包、文件原文或写入能力。
- 不读取剧情存档键 `toolbox.merge-isle.story.local.v1`，不影响任何经济、成就或云存档字段。

## 下一阶段的必备恢复门槛（本轮尚未实现）

1. 文件读取完成后首次只读预览：展示文件版本、来源可信度限制、进度回退与覆盖风险；用户可取消。
2. 对旧存档先创建**已验证且独立**的本地备份，确保异常原字节不丢失；空间不足、备份冲突时拒绝写入。
3. 明确确认后重新读取存档、重复候选合法性验证与精确基线比较，才能开展恢复事务；不得将一次预检视为永久授权。
4. 完成保存后再读回校验：失败时阻断进一步操作，保留备份并提供人工恢复路径；不可虚称回滚成功。
5. 安排双标签竞争、损坏存档、旧版文件、体积边界、刷新/重启、iPhone Safari 与微信 WebView 实机下载和导入验收。浏览器 `localStorage` 的读/写并非事务 CAS，后续仍需解决真正的原子性问题。

仅研发分支 `feat/merge-isle-p0-p1`、Draft PR #58。不得合并 main、部署 GitHub Pages/Cloudflare/Edge、修改正式导航或构建白名单、执行线上 Supabase SQL/迁移或触碰生产数据。不得添加作弊后门和未验收美术。

专项测试为 `tests/merge-save-import-preflight.test.mjs`；最新 SHA 对应的全仓库 Node 回归、静态安全/部署隔离和完整历史密钥扫描全部成功，才可将此工程增量标记为通过。即使三项检查通过，也不代表浏览器真实导入/恢复或移动端已验收。
