# P72 · 首卷仓库卡局与跨存档隔离回归（2026-10-27；未发布）

本轮针对首发剧情与真实经营交互的缺口：此前 50 个新手随机种子覆盖四章经济门槛，但模拟明确忽略仓库。新增只读、离线的真实引擎回归，覆盖仓库存放订单材料→保存→重载→取回→真实交付、仓库满/棋盘满的拒绝及通过合成释放空间、16 个随机种子的首卷里程碑仓库往返、异常仓库结构的存档保护。

测试直接调用正式 `storeItem`、`withdrawItem`、`moveOrMerge`、`fulfillOrder`、`validateSave` 与剧情存储接口；不注入资源、不修改经济规则、不向玩家开放任何作弊能力。仓库往返应只增加存档修订号，不得改变金币、体力、经验、建筑、订单或材料身份。原有剧情/普通模式存档必须保持隔离；损坏仓库结构不得静默修复覆盖。

## 本轮边界与剩余风险

这些测试是 Node 级真实引擎及离线存储契约，并非完整用户手势仿真；首卷经营模拟仍未包含真实玩家拖动、点击耗时、道具补给选择和仓库长期规划。浏览器跨标签 `localStorage` 不是原子事务，真实 iPhone Safari/微信 WebView 的 BFCache、触控与异常记录下载落盘仍需设备验收。无 Cloudflare/Pages/Edge 部署、线上 Supabase 操作、正式导航或白名单修改；PR #59 继续 Draft。提交必须保留 `[CF-Pages-Skip]`，新 SHA 的 GitHub CI 三项门禁须全部成功才算本轮验证通过。
