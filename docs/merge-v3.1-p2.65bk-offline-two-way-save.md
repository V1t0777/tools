# P2.65bk｜离线/在线双标签双向写入与备份一致性（2026-10-29）

## 发行阻塞与本轮关联验证

P2.65bj 已证明：标签 A 已加载后断网，标签 B 在线写入，A 返回前台能够采纳精确原始存档字节。但此前没有证明 A **采纳之后仍能合法写入**，以及 B 能否再次采纳 A 的离线写入。此缺口属于离线普通经营模式跨标签双向操作闭环。

本轮扩展现有真实 Chromium/CDP 双标签、Web Locks 测试，保持同源真实 localStorage 和真实页面逻辑，不替换存档运行时：

1. A 断网并采纳 B 的一次生产写入后，核验已保存状态与棋盘，找到真实材料格和空格。
2. A 先点击材料，仅允许选中，持久化原始字节必须保持不变；再点击空格，要求恰好一次 revision 增加、材料身份不变、原格清空、体力不变。
3. A 的恢复前备份必须保持原始字节不变；等待排除兼容点击重复写入。
4. B 返回前台，必须显示 A 的新棋盘并保留精确存档字节和恢复前备份；A 仍处于 offline 状态。
5. 无论断言是否成功，测试在 finally 中恢复 A 的网络模拟，避免影响后续场景。

## 验证门禁

本轮只变更 `tests/merge-browser-real.test.mjs` 与本文件，不修改运行时、经济规则、剧情文件、正式导航或部署配置。测试失败必须视为尚未闭环，不得通过跳过断言、伪造状态、自动重复危险动作或扩大时间上限掩盖。须检查最终分支 SHA 对应的全仓库 Node、`bash scripts/security-check.sh` / 部署隔离、完整历史密钥扫描三项 CI，并检查是否出现意外部署。
