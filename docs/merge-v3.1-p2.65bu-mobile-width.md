## 修复
- 原样式只在 viewport ≤360px 时启用 44px 七列棋盘，361–371px 的中间宽度可能把单格压到 44px 以下。将窄屏横向棋盘回退范围延伸到 375px，保证单格至少 44px；仍由棋盘容器局部横向滚动，不允许整页横向滚动。
- 375px 以下长预览标识在导航按钮下独立换行，避免顶部导航三列总宽度超过可用空间。正常游戏存档、重置、导入、导出及经济逻辑不变。
- Chromium 实际页面分别模拟 320、365、375、390px 宽度，断言七列棋盘格宽、页面不横向溢出、导出按钮高度、窄屏 touch-action、局部滚动和原始存档字节不变。
