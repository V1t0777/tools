# P2.65bs｜原生文件选择取消与同名存档重复选择回归（未发布）

北京时间 2026-10-30 03 时轮次。目标为普通经营模式在 iPhone Safari / 微信 WebView 常见文件选择边界上的安全性。仅扩展真实 Chromium 浏览器回归和中文记录，不改运行时、存档格式、经济数值、剧情源文件或共享样式。

## 本轮验证
1. 在真实 Chromium 页面通过导入按钮启动选择器，注入原生 input cancel 事件，要求立即释放取消按钮与导入占用，且不能弹出恢复确认、写入存档。
2. 在同一页面连续两次选择**同名同内容 JSON 文件**，每次必须重新进入独立预检与确认；两次用户均明确拒绝恢复。禁止沿用上一次授权、绕过确认或静默覆盖存档。
3. 每次拒绝后逐字节比较普通存档、恢复前备份和剧情存档；最后继续正常生产一次，要求 revision 恰好 +1、体力恰好 -1、备份不变。

浏览器使用真实 Chromium、普通模式页面、localStorage、原生 File 对象及实际业务导入流程；系统文件选择窗口、cancel/change 事件和用户确认由测试控制。这是自动化模拟，不代表 iPhone Safari 或微信 WebView 真机已验收。此前已有的双标签、Web Locks、BFCache、断网、文件落盘组合测试仍须在新 HEAD 全仓库回归中保持通过。
